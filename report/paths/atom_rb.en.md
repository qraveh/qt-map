**The idea.** A rubidium or caesium atom in an optical tweezer holds a hyperfine clock qubit, coherent for 12.6 s in a 6,100-atom caesium array [D][N6]. A global laser pulse drives neighbours toward a Rydberg state, where one excitation blocks the other: a CZ gate in ~270 ns [D][N5]. Acousto-optic deflectors (AODs) move atoms or whole code blocks so any pair can meet: connectivity is a program. The price is the clock: transport and imaging, not the gate, set a derived QEC round of 1.31 ms [S] (§7.4), 1–4.5 ms measured [D][N5][N16]. The bet: qubits that cost laser power, not fabrication, and transversal logic between moved blocks, with constant syndrome rounds per logical gate, buying back the transport time [S][N17].

**What it needs.** The gate *requires* the alkali atom and global Rydberg pulses from free-space lasers (`ct_laser`). The high-rate and algorithmic-fault-tolerance codes *require* AOD transport: moving one block onto another pairs every qubit with its partner under one pulse. Algorithmic fault tolerance *requires* correlated, loss-aware decoding, which *requires* transversal circuits; its gain, 1.73(13)× over a loss-blind decoder, rests on four rounds of one run [D][N5], none in real time. Continuous reload *replaces* one-shot loading and *conflicts* with the stored qubits, which see scattered cooling light; a reservoir carried 0.5 m by conveyors mitigates it [D][N10]. Carrier, encoding, gate, interconnect and fabrication hold one station each, code five, decoder four: the hardware is fixed, the code open. No atom–photon cavity link has joined two modules; AOD bandwidth runs out near 10⁴ atoms [S] (§2.4).

**Where it stands.** Thirteen machines, seven devices, five gate-capable. The largest, the 448-atom fault-tolerant processor (Harvard/MIT/QuEra), holds the best two-qubit error, 1.6×10⁻³ [D] (Table 8.3), and ran surface codes d=3→5 with 2.14× suppression over four rounds and up to 96 logical qubits [D][N5]. Gemini-class (QuEra; 99.2% global CZ, one shot per second [C][N4]) ran logical magic-state distillation [D][N12]; Sqale (Infleqtion) entangled 30 logical qubits in error-detecting blocks [C][N28]; Orion Alpha/Beta/Gamma (Pasqal) publishes no gate error. The largest arrays have no gate: the 6,100-qubit tweezer array [D][N6] and the continuously reloaded 3,000-atom machine, run over 2 h [D][N10]. Libra (QuEra, 2028: >256 logical qubits at 10⁻⁶) [R][N24] and Vela (Pasqal) are plans; Google's 2026 track names no species [P][N23]. Five rows have no documented cell: Hanyuan-1, Hanyuan-2, Qinghe-1, the Moscow State University prototype, the Quantum X Labs platform.

**Exceptions and borrowings.** The boundary with the analog simulator path (`atom_analog`) runs through layers 2 and 3: carrier, transport, control, readout and fabrication are shared, but the analog qubit is the ground–Rydberg pair and its computation continuous Hamiltonian evolution, with no code, decoder or link above. Pasqal crosses it both ways: Orion, filed here, lists the analog encoding and evolution as alternates; Fresnel, filed there, lists the hyperfine qubit and blockade CZ. One apparatus runs either mode, so the line divides modes, and a machine is filed by its primary one: hybrids, not errors. Orion's chip-optics alternate cites nothing. Gemini-class and Libra list fast readout as an alternate neither machine shows: mislabelled. Libra's ten-layer fit rests on a cavity cell specifying no link. The reload machine is dated August 2026 from a review; its paper is from 2025 [D][N10]. The Moscow prototype has no entangling gate yet a two-qubit error from a press statement; Quantum X Labs names no species; Hanyuan-2's inter-core link is undisclosed: data gaps. The alkaline-earth path shares gate, transport, reload, decoder and cavity; carrier and erasure encoding divide them.

**The next test.** Confirm by end-2027 (§5.2): a memory of ≥100 rounds with reloading at Λ>2 (error suppression per code-distance step) on an alkali array, and a gate-capable alkali processor above 1,180 qubits, the family frontier the alkaline-earth path has held since 2023 (§8.5, F1b). Demote if Libra slips past 2028, or two-qubit fidelity stalls at 99.9%, the ceiling a 2026 review sets for the standard CZ, with no new gate scheme [S][N7].
