## Deliverable: runner.py  (`python3 runner.py <suite> [--n N] [--seed S] [--out results/]`)
Suites, each writing `results/<suite>.jsonl` (one JSON object per compared state: state, expected sizes, actual sizes, `agree` bool, and on disagreement the symmetric differences for stations/lines/edges) and appending one line per 25 states to `progress.log` as `SUITE <name> <done>/<total> disagreements=<k>`; a final line `SUITE <name> DONE <done>/<total> disagreements=<k> seconds=<s>`:
1. `single` — every state from oracle.all_single_states (every lens × value; each toggle alone; each isolation; each station focus). Apply via the driver from a reset page each time (reset(), then the actions), read(), compare with oracle.expected.
2. `pairs` — all pairs across dimensions with a constraint model (multi-select only within one lens): lens-value × each toggle; lens-value × each isolation; toggle × isolation; isolation × focus (all 14 × 96); lens-value × focus sampled (--n, default 300, seeded); plus the full cube 8 toggle combinations × 14 isolations × marks-lens values.
3. `multi` — every Ctrl-multi-select set of size 2 and 3 within each lens (values from oracle.lens_values), with toggles off and all-on.
4. `random` — --n sequences (default 5000) of 10–40 actions drawn from: set lens, add value, remove value, toggle, isolate, clear isolate, focus, clear focus, reset, zoom, fit width, fit height, theme, lang, viewport (400/600/1024/1600 px); after EVERY step: lit set == oracle; no drawn edge touches an unlit station; legend counts (if the legend shows counts) == lit set sizes; reset returns exactly to the initial read(); fit width/height idempotent (apply twice, same transform); language switch preserves state (); no new console errors; bbox_overflow false at the current viewport.
5. `metamorphic` — on the page (not only in the oracle): adding a value never lights fewer stations of that lens; isolate then clear returns the previous set; toggling twice is identity; union over all family-lens values equals the unfiltered set (report dec_cryo separately, see RULES.md ambiguity); 200 seeded cases.
6. `static` — every station id in the DOM exists in graph.json and vice versa; every brief anchor referenced by the map resolves in the page; the RU rendering has 0 fallbacks (find how the page marks a fallback; if it cannot, say so); bilingual string tables in the page's JS have identical key sets; §7.2 table row count == 96 and its ids == graph.json ids (the table has no sort/filter — record that as N/A, do not fail).
7. `summary` — reads all results/*.jsonl and progress.log and writes `SUMMARY.md`: per suite total/agree/disagree, the distinct disagreement signatures (group by the lens/toggle/isolate/focus pattern and the kind of difference) with one example state each, coverage achieved against the SPEC's claim thresholds (100 % single, 100 % pairwise, ≥ 5000 random with 0 unadjudicated, metamorphic green).
Performance: one browser per suite, one page reused, `reset()` between states; keep each state under ~150 ms where possible; never sleep.
